# Pranav's Personal Website

A simple, minimalist website with Notion vibes to showcase writings and personal information.

## Features

- Clean, minimalist design inspired by Notion
- Responsive layout that works on all devices
- Writings section with sample articles
- About section with bullet points
- Social media links
- Smooth hover animations

## Customization

### Update Personal Information

1. **Name**: Change "I'm Pranav." in `index.html` line 15
2. **Writings**: Replace the sample articles in the writings section with your actual content
3. **About Section**: Update the bullet points in the "What I Do" section
4. **Social Links**: Update the social media URLs and email address

### Add Your Writings

Replace the sample articles in the writings section with your actual content:

```html
<article class="writing-item">
    <h3>Your Article Title</h3>
    <p>Your article description or excerpt.</p>
    <span class="date">Publication Date</span>
</article>
```

### Update Social Links

Replace the placeholder URLs with your actual social media profiles:

- Twitter: `https://twitter.com/yourusername`
- LinkedIn: `https://linkedin.com/in/yourusername`
- GitHub: `https://github.com/yourusername`
- Email: `mailto:your.email@domain.com`

## Running the Website

Simply open `index.html` in any modern web browser. No server setup required!

## Deployment

You can deploy this website to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service
